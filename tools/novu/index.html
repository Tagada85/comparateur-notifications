Novu

Israel · Noti-Fire Apps Ltd., Ramat Gan · Notification infrastructure

Official website ↗ Compare with…

Novu is a notification infrastructure for development teams, with most of its code published under the MIT license. Workflows are written in code or set up in a dashboard, and an Inbox embeds in the product along with its preferences. Novu is available as a managed service, with a region in the European Union, or as a community edition to host yourself.

Transactional notifications: order confirmations and shipping updates, password resets and authentication alerts, payment failures or renewal reminders. The notification platform is presented for transactional and lifecycle messaging; the use cases listed also include in-app feeds, digests and multi-step workflows. Pricing

Free plan

Free plan: 10,000 workflow runs per month, no credit card required. Source: novu.co/pricing · collected on Nov 5, 2026

First paid plan

Pro: from $30 per month, 30,000 workflow runs included, then $1.20 per 1,000. Source: novu.co/pricing · collected on Nov 5, 2026

What is billed

The workflow run: one execution of a workflow. Triggering a workflow to a topic of 100 subscribers counts as 100 runs. Source: novu.co/pricing · collected on Nov 5, 2026

Data & hosting

Company behind the service

Noti-Fire Apps Ltd., Ramat Gan (Israel), with a representative in the EU under Article 27 of the GDPR. Source: novu.co/privacy · collected on Nov 5, 2026

Data regions

EU region in Frankfurt (Germany), chosen when the account is created; other regions (United Kingdom, Singapore, Australia, Japan, South Korea) on Enterprise plans. Source: docs.novu.co/platform/additional-resources/security · collected on Nov 5, 2026

Data residency in the United States or the EU is included from the free plan up. Source: novu.co/pricing · collected on Nov 5, 2026

Declared cloud provider

The Security page of the documentation gives the regions, not the cloud provider. Source: docs.novu.co/platform/additional-resources/security · collected on Nov 5, 2026

Subprocessor list

Novu’s trust center only renders with JavaScript: no subprocessor list can be read in the served page. Source: trust.novu.co · collected on Nov 5, 2026

For developers

APIs and SDKs

Official (TypeScript, Python, Go, PHP, .NET, Java) and community (Laravel, Kotlin, Ruby) server SDKs for the REST API; a TypeScript Framework SDK to write workflows; web SDKs (React, headless) and a React Native mobile SDK. No native client SDK for Flutter, iOS (Swift) or Android: on those platforms, an inbox calls the Inbox REST API directly. Source: docs.novu.co/platform/sdks · collected on Nov 11, 2026

Workflows as code or via API

Novu Framework lets you write workflows in code and expose no-code controls to non-technical people. Source: docs.novu.co/framework/introduction · collected on Nov 4, 2026

Deployment model

A managed service (Novu Cloud) or a self-hosted community edition, which lacks some Novu Cloud features. Source: docs.novu.co/community/self-hosted-and-novu-cloud · collected on Nov 4, 2026

The code is published under the MIT license, except the “enterprise” code, which is under a commercial license. Source: github.com/novuhq/novu · collected on Nov 4, 2026

AI tooling

An MCP server that lets AI assistants manage workflows, subscribers and sends in natural language. Source: docs.novu.co/platform/build-with-ai/mcp · collected on Nov 4, 2026

Notification center: platforms

Client SDKs for React and React Native, and a headless client for custom interfaces. Source: docs.novu.co/platform/sdks · collected on Nov 4, 2026

Notification center: custom UI

React hooks (useNotifications, useCounts…): you handle layout and styling, Novu provides notification state, real-time updates and actions. Source: docs.novu.co/platform/inbox/headless-mode · collected on Nov 4, 2026

Notification center: preferences

A Preferences view built into the Inbox: the subscriber sets their channels for all workflows or workflow by workflow. Source: docs.novu.co/platform/inbox/configuration/preferences · collected on Nov 4, 2026

Notification center: user authentication

HMAC encryption, to be enabled before going to production, signs each subscriber identifier with a secret key; Novu checks this signature on every feed request. Source: docs.novu.co/platform/inbox/prepare-for-production · collected on Nov 4, 2026
