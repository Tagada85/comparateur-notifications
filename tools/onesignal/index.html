OneSignal

United States · OneSignal, Inc., San Mateo, California · Push & in-app messaging, Customer engagement

Official website ↗ Compare with…

OneSignal is a platform for sending mobile and web push notifications, in-app messages, emails and SMS, aimed at the product, marketing and engineering teams behind apps and websites. Messages go out from a dashboard, automated journeys or the API. SDKs integrate with mobile apps, websites and servers.

Pricing

Free plan

Free plan (Free, $0/month): unlimited mobile push and in-app messages for up to 1,000 monthly active users, web push up to 10,000 subscribers per send, 10,000 emails per month. Source: onesignal.com/pricing · collected on Nov 10, 2026

First paid plan

Growth: from $19 per month, month-to-month; mobile push at $0.012 per monthly active user, web push at $0.004 per subscriber, email: 20,000 free sends per month, then $1.50 per 1,000 sends. Source: onesignal.com/pricing · collected on Nov 10, 2026

What is billed

A fixed platform fee plus usage: mobile push is billed per monthly active user (unlimited sends and in-app messages), web push per subscriber, email and SMS by send volume. Source: onesignal.com/pricing · collected on Nov 10, 2026

For developers

APIs and SDKs

Mobile SDKs (iOS, Android, Huawei, Amazon) and a web SDK for push and in-app messages; a REST API and server SDKs (Node.js, Python, Java, Go, PHP, Ruby, C#, Rust) to send from the backend. Source: documentation.onesignal.com/docs/en/developers · collected on Nov 10, 2026

Workflows as code or via API

The REST API can create a Journey, then view and update it, and manage templates, segments and users. Source: documentation.onesignal.com/reference/rest-api-overview · collected on Nov 10, 2026

AI tooling

An AI assistant built into the dashboard (OneSignal AI) and a hosted MCP server, in open beta, that lets external assistants such as Claude, ChatGPT or Cursor operate OneSignal. Source: onesignal.com/ai · collected on Nov 10, 2026
