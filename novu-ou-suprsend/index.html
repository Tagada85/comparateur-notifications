Novu ou SuprSend ?

Deux infrastructures de notifications pour produits SaaS, comparées sur leur documentation officielle, relevée entre le 4 novembre 2026 et le 5 novembre 2026. Aucun des deux n’est classé devant l’autre : le bon choix dépend de vos critères.

En bref

Hébergement des données
Novu — Région UE à Francfort (Allemagne), choisie à la création du compte ; d’autres régions (Royaume-Uni, Singapour, Australie, Japon, Corée du Sud) sur les offres Enterprise. (source, 5 novembre 2026) La résidence des données aux États-Unis ou dans l’UE est incluse dès l’offre gratuite. (source, 5 novembre 2026) La page Sécurité de la documentation donne les régions, pas l’hébergeur cloud. (source, 5 novembre 2026)
SuprSend — La page Sécurité indique des options de résidence des données dans l’UE, sans nommer de région. (source, 5 novembre 2026) La page Sécurité ne nomme pas d’hébergeur cloud. (source, 5 novembre 2026)
Exploitation
Novu — Un service géré (Novu Cloud) ou une version communautaire auto-hébergée, à laquelle certaines fonctions de Novu Cloud manquent. (source, 4 novembre 2026) Le code est publié sous licence MIT, sauf le code « enterprise », sous licence commerciale. (source, 4 novembre 2026)
SuprSend — Un service géré (SuprSend Cloud), ou un déploiement auto-hébergé dans votre infrastructure, réservé à l’offre Enterprise et soumis à une licence. (source, 5 novembre 2026)
Ce qui est facturé
Novu — Le workflow run : une exécution d’un workflow. Déclencher un workflow vers un topic de 100 abonnés compte pour 100 runs. (source, 5 novembre 2026)
SuprSend — La notification : un message envoyé à un utilisateur ou à un objet sur un canal. Un digest qui regroupe plusieurs requêtes compte pour une. (source, 5 novembre 2026)
