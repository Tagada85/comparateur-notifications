Novu

Ce que Novu publie sur ses offres, son hébergement et ses composants, d’après ses pages officielles relevées entre le 4 novembre 2026 et le 5 novembre 2026. Chaque information renvoie à sa source ; un critère que la fiche ne montre pas n’a pas encore été relevé.

Prix et facturation

Offre gratuite
Offre gratuite : 10 000 workflow runs par mois, sans carte bancaire. (source, 5 novembre 2026)
Première offre payante
Pro : à partir de 30 $ par mois, 30 000 workflow runs inclus, puis 1,20 $ les 1 000. (source, 5 novembre 2026)
Ce qui est facturé
Le workflow run : une exécution d’un workflow. Déclencher un workflow vers un topic de 100 abonnés compte pour 100 runs. (source, 5 novembre 2026)

Hébergement et sous-traitants

Région de l’Union européenne
Région UE à Francfort (Allemagne), choisie à la création du compte ; d’autres régions (Royaume-Uni, Singapour, Australie, Japon, Corée du Sud) sur les offres Enterprise. (source, 5 novembre 2026) La résidence des données aux États-Unis ou dans l’UE est incluse dès l’offre gratuite. (source, 5 novembre 2026)
Hébergeur cloud déclaré
La page Sécurité de la documentation donne les régions, pas l’hébergeur cloud. (source, 5 novembre 2026)
Liste des sous-traitants
Le centre de confiance de Novu ne s’affiche qu’avec JavaScript : aucune liste de sous-traitants n’est lisible dans la page servie. (source, 5 novembre 2026)
Entité qui édite le service
Noti-Fire Apps Ltd., Ramat Gan (Israël), avec un représentant dans l’UE au titre de l’article 27 du RGPD. (source, 5 novembre 2026)

Exploitation et intégration

Mode d’exploitation
Un service géré (Novu Cloud) ou une version communautaire auto-hébergée, à laquelle certaines fonctions de Novu Cloud manquent. (source, 4 novembre 2026) Le code est publié sous licence MIT, sauf le code « enterprise », sous licence commerciale. (source, 4 novembre 2026)
Workflows par code ou API
Novu Framework permet d’écrire les workflows en code et d’exposer des réglages sans code aux personnes non techniques. (source, 4 novembre 2026)
Messageries
Envoi vers des messageries comme Slack, Microsoft Teams, WhatsApp, Discord et Telegram. (source, 4 novembre 2026)
Outils IA
Un serveur MCP qui permet aux assistants IA de gérer workflows, abonnés et envois en langage naturel. (source, 4 novembre 2026)

Centre de notifications

Plateformes
SDK client pour React et React Native, et un client headless pour les interfaces sur mesure. (source, 4 novembre 2026)
Interface sur mesure
Des hooks React (useNotifications, useCounts…) : vous gérez la mise en page et le style, Novu fournit l’état des notifications, le temps réel et les actions. (source, 4 novembre 2026)
Préférences
Une vue Préférences intégrée à l’Inbox : l’abonné règle ses canaux pour tous les workflows ou workflow par workflow. (source, 4 novembre 2026)
Sécurisation de l’utilisateur
Le chiffrement HMAC, à activer avant la production, signe chaque identifiant d’abonné avec une clé secrète ; Novu vérifie cette signature à chaque requête du flux. (source, 4 novembre 2026)
