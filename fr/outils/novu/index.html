Novu

Israël · Noti-Fire Apps Ltd., Ramat Gan · Infrastructure de notifications

Site officiel ↗ Comparer avec…

Novu est une infrastructure de notifications pour les équipes de développement, dont l’essentiel du code est publié sous licence MIT. Les workflows s’écrivent en code ou se règlent dans un tableau de bord, et une Inbox s’intègre au produit avec ses préférences. Novu existe en service géré, avec une région dans l’Union européenne, ou en version communautaire à héberger soi-même.

Notifications transactionnelles : confirmations de commande et suivi d’expédition, réinitialisation de mot de passe et alertes d’authentification, échec de paiement ou rappel de renouvellement. La plateforme de notifications se présente pour les messages transactionnels et de cycle de vie ; parmi les usages cités figurent aussi les fils in-app, les résumés groupés (digests) et les workflows à plusieurs étapes. Source : docs.novu.co/platform/what-is-novu · relevé le 11 nov. 2026

Prix

Offre gratuite

Offre gratuite : 10 000 workflow runs par mois, sans carte bancaire. Source : novu.co/pricing · relevé le 5 nov. 2026

Première offre payante

Pro : à partir de 30 $ par mois, 30 000 workflow runs inclus, puis 1,20 $ les 1 000. Source : novu.co/pricing · relevé le 5 nov. 2026

Ce qui est facturé

Le workflow run : une exécution d’un workflow. Déclencher un workflow vers un topic de 100 abonnés compte pour 100 runs. Source : novu.co/pricing · relevé le 5 nov. 2026

Données et hébergement

Entité qui édite le service

Noti-Fire Apps Ltd., Ramat Gan (Israël), avec un représentant dans l’UE au titre de l’article 27 du RGPD. Source : novu.co/privacy · relevé le 5 nov. 2026

Régions de données

Région UE à Francfort (Allemagne), choisie à la création du compte ; d’autres régions (Royaume-Uni, Singapour, Australie, Japon, Corée du Sud) sur les offres Enterprise. Source : docs.novu.co/platform/additional-resources/security · relevé le 5 nov. 2026

La résidence des données aux États-Unis ou dans l’UE est incluse dès l’offre gratuite. Source : novu.co/pricing · relevé le 5 nov. 2026

Hébergeur cloud déclaré

La page Sécurité de la documentation donne les régions, pas l’hébergeur cloud. Source : docs.novu.co/platform/additional-resources/security · relevé le 5 nov. 2026

Liste des sous-traitants

Le centre de confiance de Novu ne s’affiche qu’avec JavaScript : aucune liste de sous-traitants n’est lisible dans la page servie. Source : trust.novu.co · relevé le 5 nov. 2026

Pour les développeurs

API et SDK

SDK serveur officiels (TypeScript, Python, Go, PHP, .NET, Java) et communautaires (Laravel, Kotlin, Ruby) pour l’API REST ; un SDK Framework en TypeScript pour écrire les workflows ; SDK web (React, headless) et SDK mobile React Native. Pas de SDK client natif pour Flutter, iOS (Swift) ou Android : sur ces plateformes, une inbox appelle directement l’API REST de l’Inbox. Source : docs.novu.co/platform/sdks · relevé le 11 nov. 2026

Workflows par code ou API

Novu Framework permet d’écrire les workflows en code et d’exposer des réglages sans code aux personnes non techniques. Source : docs.novu.co/framework/introduction · relevé le 4 nov. 2026

Mode d’exploitation

Un service géré (Novu Cloud) ou une version communautaire auto-hébergée, à laquelle certaines fonctions de Novu Cloud manquent. Source : docs.novu.co/community/self-hosted-and-novu-cloud · relevé le 4 nov. 2026

Le code est publié sous licence MIT, sauf le code « enterprise », sous licence commerciale. Source : github.com/novuhq/novu · relevé le 4 nov. 2026

Outils IA

Un serveur MCP qui permet aux assistants IA de gérer workflows, abonnés et envois en langage naturel. Source : docs.novu.co/platform/build-with-ai/mcp · relevé le 4 nov. 2026

Centre de notifications : plateformes

SDK client pour React et React Native, et un client headless pour les interfaces sur mesure. Source : docs.novu.co/platform/sdks · relevé le 4 nov. 2026

Centre de notifications : interface sur mesure

Des hooks React (useNotifications, useCounts…) : vous gérez la mise en page et le style, Novu fournit l’état des notifications, le temps réel et les actions. Source : docs.novu.co/platform/inbox/headless-mode · relevé le 4 nov. 2026

Centre de notifications : préférences

Une vue Préférences intégrée à l’Inbox : l’abonné règle ses canaux pour tous les workflows ou workflow par workflow. Source : docs.novu.co/platform/inbox/configuration/preferences · relevé le 4 nov. 2026

Centre de notifications : sécurisation de l’utilisateur

Le chiffrement HMAC, à activer avant la production, signe chaque identifiant d’abonné avec une clé secrète ; Novu vérifie cette signature à chaque requête du flux. Source : docs.novu.co/platform/inbox/prepare-for-production · relevé le 4 nov. 2026
