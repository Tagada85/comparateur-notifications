SuprSend

États-Unis · SuprStack Inc. · Infrastructure de notifications

Site officiel ↗ Comparer avec…

SuprSend est une infrastructure de notifications pour les équipes produit et techniques qui envoient des messages sur plusieurs canaux depuis leur application. Workflows, modèles et préférences se gèrent dans un tableau de bord ou par une API de gestion, et une Inbox s’intègre au web comme au mobile. Le service est exploité par l’éditeur, ou auto-hébergé sur l’offre Enterprise.

Messages produit, transactionnels et marketing, rangés sous trois catégories racines : système (codes à usage unique, réinitialisations de mot de passe), transactionnel (confirmations de paiement, réservations, mises à jour de compte) et promotionnel (newsletters, annonces, nouveautés produit, offres) ; campagnes et annonces vers une liste ou un segment SQL (bêta). Prix

Offre gratuite

Offre gratuite : 10 000 notifications par mois, sans carte bancaire. Source : suprsend.com/pricing · relevé le 5 nov. 2026

Première offre payante

Essentials : 100 $ par mois, facturés à l’année (1 200 $), 50 000 notifications incluses, puis 2 $ les 1 000. Source : suprsend.com/pricing · relevé le 5 nov. 2026

Ce qui est facturé

La notification : un message envoyé à un utilisateur ou à un objet sur un canal. Un digest qui regroupe plusieurs requêtes compte pour une. Source : suprsend.com/pricing · relevé le 5 nov. 2026

Pour les développeurs

API et SDK

API REST et SDK serveur pour Python, Node.js, Java et Go, pour déclencher les workflows et synchroniser les utilisateurs ; SDK client web (JavaScript, React) et SDK mobiles (React Native, Expo, Flutter, iOS, Android) pour l’Inbox, le push et le centre de préférences ; webhooks pour envoyer les statuts à vos systèmes ; une CLI pour garder workflows et modèles dans Git. Source : docs.suprsend.com/docs/what-is-suprsend · relevé le 11 nov. 2026

Workflows par code ou API

Une API de gestion pour manipuler workflows, modèles, schémas et traductions par programme, et les pousser ou les tirer d’un espace de travail à l’autre. Source : docs.suprsend.com/docs/management-api-overview · relevé le 5 nov. 2026

Mode d’exploitation

Un service géré (SuprSend Cloud), ou un déploiement auto-hébergé dans votre infrastructure, réservé à l’offre Enterprise et soumis à une licence. Source : docs.suprsend.com/docs/self-hosted/introduction · relevé le 5 nov. 2026

Outils IA

Un serveur MCP hébergé (mcp.suprsend.com) pour piloter SuprSend depuis Claude, ChatGPT, Cursor ou VS Code. Source : suprsend.com/privacy · relevé le 5 nov. 2026

Centre de notifications : plateformes

Inbox pour React, JavaScript (Angular, Vue…) et React Native ; iOS et Flutter en mode headless. Source : docs.suprsend.com/docs/inbox-overview · relevé le 4 nov. 2026

Centre de notifications : interface sur mesure

Des hooks et des fournisseurs de contexte React pour construire son propre flux, avec un contrôle complet du style et de la mise en page. Source : docs.suprsend.com/docs/react-sdk-headless-feed · relevé le 4 nov. 2026

Centre de notifications : préférences

Une page de préférences prête à intégrer, synchronisée avec les catégories définies dans le tableau de bord, et des hooks pour une interface sur mesure. Source : docs.suprsend.com/docs/embedded-preference-centre · relevé le 4 nov. 2026

Centre de notifications : sécurisation de l’utilisateur

Le mode de sécurité renforcée, recommandé en production, exige un jeton utilisateur (JWT) signé par votre serveur ; SuprSend juge la seule clé publique insuffisante en production. Source : docs.suprsend.com/docs/client-authentication · relevé le 4 nov. 2026
