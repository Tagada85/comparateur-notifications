Courier

États-Unis · trycourier.com, Inc., San Francisco · Infrastructure de notifications

Site officiel ↗ Comparer avec…

Courier est une infrastructure de notifications pour les équipes produit et techniques : une API envoie un même message par email, SMS, push, in-app ou messagerie. Elle fournit un centre de notifications intégrable, un composant de préférences et des séries de messages déclenchées par un événement. Le service est exploité par l’éditeur, aux États-Unis ou dans l’Union européenne.

Business : 0,005 $ par envoi au-delà des 10 000 envois gratuits par mois. Source : courier.com/pricing · relevé le 5 nov. 2026

Ce qui est facturé

L’envoi : un modèle envoyé à un destinataire. Un modèle multicanal compte pour un seul envoi, même s’il part par email, SMS et push ; un envoi à une liste de 100 utilisateurs en compte 100. Source : courier.com/docs/workspaces/billing · relevé le 5 nov. 2026

Données et hébergement

Entité qui édite le service

Régions de données

Deux datacenters séparés, aux États-Unis et dans l’UE (Irlande), sans données partagées ; le datacenter UE est ouvert sur les offres payantes (Business et Enterprise). Source : courier.com/docs/workspaces/datacenters · relevé le 5 nov. 2026

Amazon Web Services pour l’infrastructure cloud, aux États-Unis et dans l’UE (liste des sous-traitants mise à jour le 3 août 2026). Source : courier.com/subprocessors · relevé le 5 nov. 2026

Liste des sous-traitants

Liste publique mise à jour le 3 août 2026 : 15 sous-traitants, dont 9 situés « USA & EU » et 6 aux États-Unis seulement. Source : courier.com/subprocessors · relevé le 5 nov. 2026

Pour les développeurs

API et SDK

Une API REST pour l’envoi, les utilisateurs, les préférences et le reste ; SDK serveur pour Node, Python, Go, Ruby, Java, PHP et C# ; SDK client pour React et JavaScript, et SDK mobiles pour iOS, Android, React Native et Flutter, pour les inbox in-app et les préférences ; webhooks sortants pour suivre chaque changement de statut ; une CLI. Source : courier.com/docs/overview · relevé le 11 nov. 2026

Workflows par code ou API

Les journeys (séries de messages déclenchées par un événement) se créent par l’API : un déclencheur, des étapes, une sortie, puis une publication. Source : courier.com/docs/get-started/build-your-first-journey · relevé le 5 nov. 2026

Mode d’exploitation

Un service géré, exploité par Courier dans deux datacenters séparés, aux États-Unis et dans l’UE. Source : courier.com/docs/workspaces/datacenters · relevé le 5 nov. 2026
