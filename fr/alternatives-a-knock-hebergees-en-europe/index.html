Alternatives à Knock hébergées en Europe

Où en est Knock : Knock annonce une résidence des données dans l’Union européenne d’ici la fin de 2026. (source, 5 novembre 2026) Amazon Web Services pour l’hébergement et l’infrastructure cloud, aux États-Unis (liste des sous-traitants mise à jour le 10 juin 2026). (source, 5 novembre 2026)

Si vos données doivent rester dans l’Union européenne avant cette date, cette page montre qui le propose déjà, puis ce que vous retrouverez de Knock chez chacun, d’après leurs pages relevées du 4 au 11 novembre 2026. Les éditeurs sont présentés par ordre alphabétique ; la liste n’est pas exhaustive, et aucun ne paie pour y figurer.

Qui propose de garder les données dans l’Union européenne

Courier
Deux datacenters séparés, aux États-Unis et dans l’UE (Irlande), sans données partagées ; le datacenter UE est ouvert sur les offres payantes (Business et Enterprise). (source, 5 novembre 2026)
Novu
Région UE à Francfort (Allemagne), choisie à la création du compte ; d’autres régions (Royaume-Uni, Singapour, Australie, Japon, Corée du Sud) sur les offres Enterprise. (source, 5 novembre 2026) La résidence des données aux États-Unis ou dans l’UE est incluse dès l’offre gratuite. (source, 5 novembre 2026)
SuprSend
La page Sécurité indique des options de résidence des données dans l’UE, sans nommer de région. (source, 5 novembre 2026)

MagicBell n’est pas dans cette liste : La page Sécurité affirme la conformité au RGPD, sans indiquer de région d’hébergement. (source, 5 novembre 2026) La région ne dit ni où sont situés les sous-traitants, ni de quel pays relève l’éditeur : voir hébergement, région UE et sous-traitants.

Workflows par code ou API

Vos workflows vivent peut-être dans votre dépôt et votre CI.

Chez Knock : La CLI de Knock permet de travailler les workflows et les modèles en local, et de commiter puis promouvoir les changements depuis une chaîne CI/CD. (source, 4 novembre 2026)

Courier
Les journeys (séries de messages déclenchées par un événement) se créent par l’API : un déclencheur, des étapes, une sortie, puis une publication. (source, 5 novembre 2026)
Novu
Novu Framework permet d’écrire les workflows en code et d’exposer des réglages sans code aux personnes non techniques. (source, 4 novembre 2026)
SuprSend
Une API de gestion pour manipuler workflows, modèles, schémas et traductions par programme, et les pousser ou les tirer d’un espace de travail à l’autre. (source, 5 novembre 2026)

Ce qui est facturé

Le même volume ne se compte pas pareil d’un éditeur à l’autre.

Chez Knock : Le message envoyé : un message remis à un utilisateur sur un canal. Un déclenchement qui produit un message in-app et un email compte pour deux. (source, 5 novembre 2026)

Courier
L’envoi : un modèle envoyé à un destinataire. Un modèle multicanal compte pour un seul envoi, même s’il part par email, SMS et push ; un envoi à une liste de 100 utilisateurs en compte 100. (source, 5 novembre 2026)
Novu
Le workflow run : une exécution d’un workflow. Déclencher un workflow vers un topic de 100 abonnés compte pour 100 runs. (source, 5 novembre 2026)
SuprSend
La notification : un message envoyé à un utilisateur ou à un objet sur un canal. Un digest qui regroupe plusieurs requêtes compte pour une. (source, 5 novembre 2026)

Canaux

Les messageries que vos utilisateurs reçoivent déjà.

Chez Knock : Email (canal intégré ou fournisseurs comme Amazon SES, Postmark, SendGrid ou SMTP), SMS, push mobile par APNs (iOS), Firebase Cloud Messaging (Android), Expo (React Native) et OneSignal, flux in-app et guides in-app, et messageries : Slack, Discord, Microsoft Teams et WhatsApp. (source, 11 novembre 2026)

Courier
Email, SMS, push mobile (iOS, Android, React Native) et push web, inbox in-app (Courier Inbox), et messageries : Slack, Microsoft Teams, WhatsApp, Discord, Facebook Messenger et Viber. (source, 11 novembre 2026)
Novu
Inbox in-app, email, SMS, push vers les applications mobiles et web (push mobile et push web : FCM, APNs, Expo, OneSignal, Pushpad…) et messageries : Slack, Discord, Microsoft Teams, WhatsApp Business, Telegram, Mattermost, Webex, Zulip… (source, 11 novembre 2026)
SuprSend
Email, SMS, WhatsApp, push mobile et push web, Inbox in-app, Slack et Microsoft Teams, depuis une seule API ; les messages Slack et Teams peuvent aller dans les espaces de travail de vos clients. (source, 11 novembre 2026)

Avant de migrer

Ce qu’il faut inventorier chez vous, quel que soit l’éditeur choisi :

  • les workflows et les modèles de messages, et l’endroit où ils sont versionnés ;
  • les préférences que vos utilisateurs ont enregistrées, pour ne pas leur renvoyer ce qu’ils ont refusé ;
  • l’historique du centre de notifications, que vos utilisateurs s’attendent à retrouver ;
  • votre volume mensuel, recompté dans l’unité du nouvel éditeur : combien coûte une infrastructure de notifications ?

Knock face à un candidat, critère par critère : Courier ou Knock ? et Knock ou Novu ?

Ce que cette page ne couvre pas

Cette page n’est pas un avis juridique, et nous n’avons pas testé de migration : elle compare ce que les éditeurs publient. Elle ne dit pas comment exporter vos données de Knock, ni comment chaque candidat les importe. Une information a changé ? Signalez-la.
